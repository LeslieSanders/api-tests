# 📡 API Testing with Postman – Reqres API

This project showcases a sample API test suite using [Postman](https://www.postman.com/) for the [Reqres API](https://reqres.in/). It demonstrates my ability to create, run, and validate API requests with automated tests.

---

## 🔍 What’s Included

- ✅ **GET Users API**: `https://reqres.in/api/users?page=2`
- ✅ Test collection created in Postman
- ✅ Automated test scripts for:
  - Status code = 200
  - Validating response contains user data

---

## 📁 File Details

| File | Description |
|------|-------------|
| `user-api-tests.postman_collection.json` | Postman collection with test cases |

---

## 🛠 Tools Used

- Postman v10+
- JavaScript assertions in Test tab
- Reqres REST API for dummy data

---

## 📌 How to Use This

1. Import the `.json` file into Postman
2. Run the request
3. View **Test Results** to verify all pass ✅
